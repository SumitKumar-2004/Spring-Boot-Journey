# Spring Boot Learning

A practical learning repository covering the fundamentals of **Spring Framework, Spring Boot, REST APIs, Spring Data JPA, Hibernate, JDBC, and backend development concepts**.

This repository contains small examples and practice implementations created while learning Spring Boot and related technologies.

## 🚀 Topics Covered

### Spring Framework & Spring Core

* Spring Framework fundamentals
* Inversion of Control (IoC)
* Dependency Injection (DI)
* Spring Beans
* Bean Lifecycle
* Bean Scopes
* Lazy & Eager Initialization
* Circular Dependency
* XML-based Configuration
* `@Component`, `@Bean`, `@Autowired`

### Spring Boot

* Spring Boot fundamentals
* Spring Boot Application Structure
* Auto Configuration
* `@SpringBootApplication`
* Application Properties
* Configuration using `application.properties`
* Maven & `pom.xml`

### REST API Development

* REST API fundamentals
* HTTP methods
* Request & Response handling
* Controllers
* Service Layer
* Repository Layer
* CRUD REST APIs
* DTOs
* Validation
* Exception Handling
* Global Exception Handling

### Database & Persistence

* MySQL integration
* JDBC
* JdbcTemplate
* Spring Data JPA
* JPA Repositories
* Hibernate
* Entity Mapping
* Persistence Context
* Transactions
* First-Level Cache
* Soft Delete

### JPA Relationships

* One-to-One
* One-to-Many
* Many-to-One
* Many-to-Many
* Cascading
* Lazy Loading
* N+1 Problem
* EntityGraph

### Advanced Spring Concepts

* Spring MVC
* DispatcherServlet
* Servlet & Tomcat fundamentals
* Filters
* Interceptors
* Spring AOP
* Cross-Cutting Concerns
* Proxies
* Advice & Pointcuts
* Custom Annotations
* Spring Profiles
